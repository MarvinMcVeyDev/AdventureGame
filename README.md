# JavaScript Adventure Game
## Overview

A browser-based adventure game built with JavaScript, HTML, and CSS. This project explores interactive gameplay, player choices, and the use of JavaScript to create a dynamic experience within a web browser.
The project is currently available as source code and has not been published as a live web application.

## Features

Interactive gameplay using JavaScript
Player choices that influence the game experience
Dynamic updates to the page based on game logic
Browser-based interface built with HTML and CSS
Update these features to match the mechanics currently implemented in the game.

## Technologies Used

HTML5

CSS3

JavaScript

## What I Learned

This project helped me practice:

Writing JavaScript to control application behavior
Working with user input and interactive elements
Manipulating webpage content through the DOM
Organizing game logic and managing different gameplay states
Debugging and testing interactive functionality

## Running the Project

The game has not been deployed to a live website.

To run it locally:

Clone or download this repository.

Open the project folder.

Open the main HTML file in a web browser.
